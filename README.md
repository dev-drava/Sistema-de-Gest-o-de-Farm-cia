# Sistema-de-Gest-o-de-Farm-cia
Sistema de Gestão de Farmácia em Python com arquitetura cliente-servidor (Sockets) e base de dados MySQL. Suporta três perfis (Administrador, Farmacêutico e Cliente) com gestão de medicamentos, vendas, stock e faturação. Projeto de PSI (Módulo 15) que aplica herança e módulos.
